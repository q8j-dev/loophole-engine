# Product

Loophole Engine turns a short Python description of a level into a 3D game for Scratch and TurboWarp. Gameplay stays in ordinary Scratch blocks.

## Audience (inferred from the brief and the repo)

Scratch and TurboWarp users, roughly ages 10 to 16, many of whom cannot install Python or use a terminal. Secondary: older hobbyists and teachers who want the command line.

## Surfaces

- README and docs on GitHub (Read).
- Loophole Studio in the browser (Operate): edit `world.py`, build the game, play it or download it.
- Prebuilt example games on the GitHub Release.

## Tone (inferred)

Plain, friendly and direct. Written for a curious 12-year-old without talking down. No jargon a Scratch user would not know.
